## Breaking, v4

These change the current library api.

- [ ] dynamic columns know their table and column, for custom decoders
- [ ] only generate `Param` variants the engine needs (f.e. sqlite)
- [ ] prefix names to avoid conflicts between schemas (postgres, mysql)
