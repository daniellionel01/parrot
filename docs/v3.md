## CLI

* log unexpected errors to build/.parrot/crash_report.log
* use https://github.com/TanklesXL/glint
* support sqlc migrations (https://docs.sqlc.dev/en/stable/howto/ddl.html#handling-sql-migrations)
* configure output module

```sh
$ gleam run -m parrot help
```

```sh
$ gleam run -m parrot generate
> downloading sqlc binary...

> Could not find the specified sqlc version `...`. 
  Versions are specified like this: `v1.30.0`. A list of all available sqlc versions can be found
  here: https://github.com/sqlc-dev/sqlc/releases/.
```

```sh
$ gleam run -m parrot generate
> downloading sqlc binary...
> generating gleam code...
```

```sh
$ PARROT_DEBUG=1 gleam run -m parrot generate
> downloading sqlc binary...
> parsing sql queries...
> generating gleam code ...
```
